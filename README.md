# ArticulPro — PWA pour Diction, Articulation & Grammaire Française (B1-C2)

Application web progressive (PWA) prête à être déployée gratuitement sur **GitHub Pages**.

## 🚀 Déploiement rapide sur GitHub Pages

1. Créez un nouveau dépôt sur votre compte GitHub (ex: `articulpro`).
2. Transférez tous les fichiers extraits du ZIP (`index.html`, `manifest.webmanifest`, `sw.js`) sur votre dépôt.
3. Allez dans **Settings > Pages** de votre dépôt GitHub.
4. Dans **Source**, sélectionnez la branche `main` (ou `master`), dossier `/(root)` et cliquez sur **Save**.
5. Votre application sera en ligne à l'adresse `https://<votre-pseudo>.github.io/<votre-depot>/` !
